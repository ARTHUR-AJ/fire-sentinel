# fire-sentinel

Fire Sentinel is a web project intended to help people view and understand wildfire information. The project is in its early stages; fire detection, alerts, and live data are not implemented yet.

## Current status

The `web/` folder contains a basic Next.js application. Mapping libraries are included as dependencies, but the map and fire monitoring features still need to be built.

## Tech stack

- Next.js
- React
- TypeScript
- Leaflet and React Leaflet
- Turf.js

## Getting started

You’ll need Node.js and npm installed.

```bash
cd web
npm install
npm run dev
